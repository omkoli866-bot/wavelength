Privacy

Last updated August 2026

This page describes the reference implementation as shipped. If you deploy your own copy of this site, update this page to match what your server actually does.

Guest chats vs. registered accounts

You don't need an account to use Wavelength. As a guest, nothing changes from before: your gender and who you'd like to talk to are used only to find a match, and your messages aren't written to a database — they exist only in memory for the length of the conversation.

If you create an account, that's different: your username and a securely hashed password are stored, and conversations with other registered users are saved so you can view them again and reconnect with people you've added as contacts. A conversation is only saved if both people in it are logged in — chatting with a guest is never saved, even if you're registered.

What passes through the server

Messages are relayed live between two matched people over a WebSocket connection. For guest-to-guest or guest-involved chats, nothing is written to a database or log file. For chats between two registered users, message content is stored so it can be shown to both participants later.

What is logged

Basic connection metadata (like IP address, for abuse prevention and rate limiting) may be logged by the hosting infrastructure, and reports submitted through the Report button are logged so they can be reviewed. This is standard practice for any live web service and is necessary to respond to abuse.

Cookies and tracking

The reference site doesn't use analytics or advertising trackers. Login sessions are stored in your browser's local storage, not cookies, and only sent to the server to authenticate your requests.

Your choices

Guest sessions leave nothing to delete — closing the tab ends everything immediately. If you've registered, you can request deletion of your account and its stored conversations by contacting the site operator; this reference implementation doesn't yet include a self-service delete button, which you should add before running this for the public.
