Privacy

Last updated August 2026

This page describes the reference implementation as shipped. If you deploy your own copy of this site, update this page to match what your server actually does.

What we don't collect

There's no account system. We don't ask for your name, email, or any profile information. The only inputs are the gender you select and who you'd like to talk to — both are used only to find you a match and aren't stored beyond your session.

What passes through the server

Messages are relayed live between two matched people over a WebSocket connection. The reference server does not write chat messages to a database or log file — they exist only in memory for the duration of the connection.

What is logged

Basic connection metadata (like IP address, for abuse prevention and rate limiting) may be logged by the hosting infrastructure, and reports submitted through the Report button are logged so they can be reviewed. This is standard practice for any live web service and is necessary to respond to abuse.

Cookies and tracking

The reference site doesn't use analytics, advertising trackers, or third-party cookies. It uses a session identifier only to keep your WebSocket connection alive.

Your choices

Because nothing is tied to an account, there's nothing to delete on request beyond what standard server logs retain. Closing the tab ends your session immediately.
